# Design references

The DroidLab Home, Code Editor, Tools, Settings, and Import APK reference images were generated during the product-design conversation and are the approved visual direction.

The current GitHub integration can create text files and Git objects, but the generated image attachments are not available to that integration as local binary files in this session. Therefore, the images have not been uploaded here. The visual system, screen anatomy, and interaction requirements are documented in docs/UI_REFERENCE.md.

When image files are available in a local development workspace, add the original generated files to this folder without recompressing or altering them, and update this note with their filenames.
