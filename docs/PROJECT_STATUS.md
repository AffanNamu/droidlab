# Project status

Last updated: 2026-11-10

## Repository
- Repository: AffanNamu/droidlab

## Implemented in repository
- Product README and no-account/local-first product decision.
- Architecture, security, engine compatibility, Android permission policy, roadmap, UI reference, development setup, and project status documentation.
- ADRs for local-first product scope, Flutter/Kotlin boundary, and evidence-based engine readiness.
- Flutter package manifest, lint configuration, ignore rules, Android bootstrap script, and GitHub Actions workflow.
- Flutter app entry point, shared dark theme, and functional five-tab navigation shell.
- Home dashboard with native engine capability diagnostics, Projects catalog, Workspace empty state, Tools catalog, and Settings catalog.
- Import APK screen with Installed Apps, System Apps, and APK Files tabs, search, multi-selection, app icons, package/version/size metadata, and extraction actions.
- Single APK file selection through the Android Storage Access Framework-backed file picker.
- Domain models for projects, engine capability states, and persistent job status transitions.
- Typed Pigeon contract for installed-app discovery, installed-app extraction, single APK file import, project listing, engine capabilities, install permission, PackageInstaller sessions, and install status.
- Kotlin installed-app discovery and base/split APK extraction implementation.
- Kotlin APK file import into a private project workspace.
- Kotlin project catalog with per-project metadata and SHA-256 hashes for original APK files.
- Kotlin PackageInstaller session coordinator and per-job status receiver.
- Kotlin Pigeon host API implementation and MainActivity registration source.
- Initial widget test and job state-machine tests.
- Design reference specification; generated image binaries have not been uploaded because they were not available to the GitHub integration as local binary files.

## Not implemented or not yet verified
- Complete Android Gradle platform files and Pigeon-generated bindings are generated by bootstrap/CI; their generation has not yet been confirmed in a completed build.
- Kotlin engine and Pigeon bridge have not yet been compiled or tested on a physical Android device.
- APKS/XAPK and split-container file import.
- Local Drift database; the first native project catalog currently uses per-project JSON metadata and must be migrated to the planned database.
- APK inspector, JADX, Apktool, Smali, build/sign/verify engines.
- PackageInstaller flow is implemented as a native coordinator but is not yet device-tested or exposed in the UI.
- Functional code editor and real project file browsing.
- Android source-project ZIP import and local Gradle build environment.

## Important truth
DroidLab is not yet a release-ready APK editor. Installed-app discovery, APK extraction, single-APK file import, project metadata, and installation coordinator source are present but are not yet compiled or device-tested. Reverse engineering, rebuilding, signing, verification, and the full install workflow are not yet complete end-to-end. No engine is marked ready without native evidence.
