## Not implemented yet

- Kotlin/Pigeon bridge.
- Local database and workspace.
- SAF importer and installed-app picker.
- APK inspector, JADX, Apktool, Smali, build/sign/verify engines.
- PackageInstaller integration.
- Code editor, Projects, Tools, Settings screens beyond the home shell.

## Important truth
The current Flutter screen is a foundation scaffold, not a functional APK editor. Import buttons and tool chips are visual placeholders and do not claim to import or modify applications. Do not distribute this state as a working APK editor.
