## Not implemented or not yet verified
- Complete Android Gradle platform files are generated by bootstrap/CI; they are not yet confirmed committed as a full native platform scaffold.
- Pigeon-generated Dart/Kotlin bindings are generated by bootstrap/CI; generation has not yet been verified in a completed run.
- Kotlin bridge registration and host API implementation.
- Local database and workspace file manager.
- SAF APK/source ZIP import UI and installed-app picker UI.
- APK inspector, JADX, Apktool, Smali, build/sign/verify engines.
- PackageInstaller flow is implemented as a native coordinator but is not yet wired to Flutter or device-tested.
- Functional code editor and real project file browsing.

## Important truth
The current Flutter UI is a foundation scaffold, not a functional APK editor. Import actions show an explicit not-implemented message; tool catalog entries are informational. Native discovery and install source code is present but has not yet been compiled or tested on a device. No engine is marked ready without native evidence. Do not distribute this state as a working APK editor.
