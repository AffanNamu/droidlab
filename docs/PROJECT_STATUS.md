## Not implemented yet
- Complete Android Gradle platform files are generated by bootstrap/CI and are not yet committed as a full native platform scaffold.
- Kotlin/Pigeon bridge and native capability discovery.
- Local database and workspace file manager.
- SAF importer and installed-app picker.
- APK inspector, JADX, Apktool, Smali, build/sign/verify engines.
- PackageInstaller integration.
- Functional code editor and real project file browsing.

## Important truth
The current Flutter UI is a foundation scaffold, not a functional APK editor. Import actions show an explicit not-implemented message; tool catalog entries are informational. No engine is marked ready without native evidence. Do not distribute this state as a working APK editor.
